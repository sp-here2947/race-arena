
# Race Arena — CPU Scheduling Simulator

Race Arena is an interactive CPU scheduling simulator designed to demonstrate and compare operating system scheduling algorithms. Users can create process workloads, run scheduling simulations, visualize CPU execution through Gantt charts, and analyze performance metrics.

## Features

- **Multiple Scheduling Algorithms:** Simulate FCFS (First Come First Served), SJN (Shortest Job Next), and Round Robin.
- **Custom Workloads:** Add processes and configure their arrival times and CPU burst times.
- **Round Robin Configuration:** Adjust the time quantum to observe its effect on scheduling.
- **Gantt Chart Visualization:** View the execution order and time intervals of processes.
- **Performance Analysis:** Compare completion time, turnaround time, waiting time, and average metrics.
- **Interactive Interface:** Explore scheduling behavior through a responsive, user-friendly web interface.

## Technologies Used

- JavaScript
- React
- Next.js
- TypeScript
- Tailwind CSS

## Learning Objectives

Race Arena helps visualize how CPU scheduling algorithms work and how their choices affect process waiting time, turnaround time, and overall scheduling performance.
